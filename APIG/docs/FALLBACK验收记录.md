## 验收边界

Fallback 必须由**模型网关**完成主、备模型路由和故障切换；不能以 Agent 代码改模型地址、客户端直连备用模型、MCP 工具故障或手工重试替代本项验收。

当前业务链路：`用户 → APIG → 云上存量诊断应用 → Agent Runtime → 模型网关`；仅模型推理走模型网关，存量业务查询仍由 `yingteng_test` MCP 完成。
