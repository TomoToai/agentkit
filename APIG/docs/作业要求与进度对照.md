## 原始作业目标

准备一个具备行业属性的企业“存量应用系统”，使用 MCP 网关实现存量应用转换，使用模型网关实现模型代理，最终实现 Agent 可正确使用“存量应用系统”。

## 已创建的云端资源

- Agent Runtime：`yingteng-camera-ai-diagnosis`，当前版本 `v3`，状态 `Ready`。
- HTTP 转 MCP 服务：`yingteng_camera_http_mcp_v2`，直连返回 5 个工具。
- MCP 工具集：`yingteng_camera_toolset`，模式 `AllTools`（全量返回），不是语义检索工具集。
- 模型网关：Runtime 主模型已通过模型网关配置；Fallback 未验收。

## 当前事实与边界

- 我们的存量系统是本地 Web Demo：`http://127.0.0.1:8000/`，当前不要求 Web 登录；“安全认证”指存量 REST API 的 API Key。
- Web 右侧 AI 诊断助手已完成前后端入口：浏览器 → `/api/agent/chat` → `yingteng-camera-support`。Runtime 调用地址和调用 Key 待注入服务端环境变量后联调。
- 当前 5 个 MCP 工具定义、Agent 业务指令和存量 API 链路均已验收；Fallback 仍受模型网关控制面权限限制，不能把基线调用当作故障切换完成。
