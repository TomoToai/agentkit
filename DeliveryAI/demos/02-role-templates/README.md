# Demo 场景 2：Agent 角色标准化沉淀

> **受众**：多项目并行的研发团队，希望将"需求分析师/Coder/Tester"等角色标准化、模板化，降低每个项目重复配置成本。

## Demo 目标
1. 展示系统内置 Agent 模板（需求分析师、Coder、Tester、发布 Agent）
2. 演示如何基于内置模板复制微调，创建自定义角色模板
3. 演示模板与流程节点绑定，形成"节点 = 角色"的稳定映射

## 演示剧本（预计 10 分钟）

### Step 1：系统内置模板展示（2 min）
1. 进入「Agent 配置」→「模板管理」
2. 逐个点开系统内置模板，展示每个模板的：
   - 系统提示词（角色定义、职责边界、输出规范）
   - 默认绑定的模型
   - 默认绑定的 Skill / MCP

### Step 2：自定义角色模板创建（4 min）
**示例：为金融业务线定制一个「合规敏感 Coder Agent」**

1. 选择系统内置「Coding Agent」→ 点击「复制为自定义模板」
2. 命名：`合规敏感 Coder Agent - 金融线`
3. 修改系统提示词，追加金融合规要求：
   - 禁止在代码中硬编码任何密钥、银行卡号、身份证号
   - 涉及用户数据的字段必须走统一脱敏组件
   - 日志输出禁止打印用户 PII 信息
   - 新增代码必须包含 License Header
4. 模型：选择 `Doubao 2.0 Pro`（如需更强推理可切更大模型）
5. 绑定额外 Skill：
   - `静态代码扫描 Skill`（执行 SonarQube/ESLint）
   - `敏感信息检测 Skill`（扫描提交前 diff 中的敏感词）
6. 保存模板，设置版本号 v1.0，填写变更记录

### Step 3：模板绑定到流程节点（2 min）
1. 进入「流程管理」→ 打开目标流程编辑
2. 找到「编码实现」节点
3. Agent 选择：`合规敏感 Coder Agent - 金融线`
4. 保存并启用流程
5. 演示：用同一条需求在旧/新两个流程各跑一次，对比代码输出差异（尤其合规相关部分）

### Step 4：模板复用与治理（2 min）
1. 展示模板列表页：显示每个模板的
   - 负责人
   - 版本号与最近变更时间
   - 被多少条流程/节点引用
   - 使用统计（执行次数、成功率、平均耗时）
2. 演示「版本回滚」功能：如 v1.0 效果不佳，可一键切回系统内置版本
3. 展示权限控制：只有模板负责人或空间管理员可编辑模板
