# 流程模板（Flow Templates）

存放从 DeliveryAI 控制台导出的**流程模板配置**（JSON/YAML），供空间管理员在「流程管理」中一键导入。

## 建议内容
- `end-to-end-flow.json` —— 6 节点完整流程：需求澄清 → Spec 设计 → 编码实现 → 联调测试 → MR → 发布
- `half-ai-flow.json` —— 半 AI 流程：仅需求澄清 + Spec 为 AI 节点，其余人工（用于渐进式落地阶段 1）

## 导入方式
空间管理员 → 空间「设置」→「流程管理」→「导入流程」→ 选择本目录下的 JSON。

> 真实模板需在控制台配置完成后导出，暂以占位说明为准。
