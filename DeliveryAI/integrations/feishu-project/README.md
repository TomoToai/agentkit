# 飞书项目集成（Feishu Project）

存放 **飞书项目需求系统** 的集成配置示例与说明。

## 需要准备
- 飞书项目 App ID / App Secret（企业管理员在控制台「企业集成」配置）
- 绑定的需求空间标识
- 关联的工作流模板（需与 `../../flows/templates/` 中导入的流程对应）
- 基准分支与标签规则

## 说明
- 需求的正式创建入口在**飞书项目**中，不在 DeliveryAI 客户端内。
- 需求创建后自动同步至 DeliveryAI 进入需求澄清节点。

> 敏感凭据请写入项目根目录 `.env`，勿提交到 git（参考根目录 `.gitignore`）。
